### 디자인·품질 원칙 (항상 적용)
- **브랜드 컬러는 핫핑크.** 팔레트: brand #FF2E88 / hover #E61E75 / tint #FFE4EF, 텍스트 ink #17121F — **학생 모드 · 랜딩 · 공개 페이지**에서다. 관리자 모드는 아래.
- **관리자 모드(`/admin`)는 토스 모양이다 — 파랑 하나 · 회색 바탕 · 흰 카드** (2026-10-09 Alan — "지금 관리자모드에서도 전부다 핑크로 디자인되어있어서 눈이 아픈것 같아.
  관리자모드는 토스 디자인처럼 해줄 수 있어?"). 바꾸는 곳은 **`globals.css` 의 `:root:has([data-admin-theme])` 한 블록**이고 `AdminShell` 이 그 속성을 그린다 —
  브랜드 토큰 열 개와 글자 · 선 · 바탕 일곱 개를 토스 팔레트(파랑 #3182f6 · 글자 #191f28 · 회색 #8b95a1 · 선 #e5e8eb · 바탕 #f2f4f6 · 카드 흰색)로 덮어쓴다.
  **화면 조각은 그대로 `bg-brand-500` · `text-brand-700` 을 쓰고 값만 바뀐다** — 그래서 관리자 화면 · 조각에 **핑크 hex 를 직접 적지 말 것**(토큰을 써야 두 모드가 갈린다).
  차트 색(`charts/palette.ts`)도 변수다. `:root` 에 거는 까닭은 헤더의 모드 배지 · 햄버거 서랍 · 하단 바 · 팝업처럼 AdminShell 바깥에 그려지는 것까지 같은 벌이어야 해서다.
  `src/lib/admin-theme.test.ts` 가 못박는다 (토큰 열일곱 전부 · 그림자 · 아이콘 · AdminShell 속성 · 관리자 파일의 핑크 hex 0 · 학생 쪽 토큰은 그대로).
  - **그림자**: Tailwind 가 색을 값에 박아 넣어 변수로 안 바뀐다 — 같은 블록이 `.shadow-soft` · `.shadow-pink` · `.btn-primary` 의 `--tw-shadow` 를 거의 없는 그림자로 갈아 끼운다 (토스는 카드 · 버튼에 그림자가 거의 없다).
  - **아이콘**: 힉스필드 PNG 가 잉크 + 핫핑크 2톤이라(전부 그 둘뿐) `<Icon>` 이 다는 `data-icon` 에 `hue-rotate` 로 핑크를 파랑으로 돌린다 (크로미움에서 재서 #2178eb).
    `brightness-0 invert`(흰 아이콘) · `grayscale` 과 겹치도록 Tailwind 의 filter 변수 목록을 뒤에 잇는다 — 빼면 흰 아이콘이 다시 색을 띤다. **새 아이콘에 핑크 · 잉크 밖의 색을 넣으면 그 색도 돈다.**
  - **모양**: 카드 테두리는 거의 안 보이게(#edf0f4), `btn-primary` · `btn-secondary` · `btn-dark` 는 알약이 아니라 둥근 네모(14px). 사이드바의 켜진 줄은 연한 바탕 + 파란 글자(꽉 찬 칸 · 그림자 없음),
    휴대폰 상단 탭의 켜진 칸은 잉크색 알약, `FilterTabs` 의 `solid` 띠는 흰 띠 안에 파란 칸. 대시보드의 큰 숫자(처리 대기 · 총인원)는 잉크색 — 토스는 숫자를 검게, 파랑은 누르는 곳에만 쓴다.
  - 숙제 미제출 격자의 '냄' 표시(`.hw-mark-done`)는 그림 안에 변수를 못 넣어 **마스크 + 바탕색**으로 그린다. 반 편성 달력의 '이미지 저장'(캔버스)은 학원 전달용이라 브랜드 핫핑크 그대로다 (`ALLOWED`).
  - **학생 모드로 돌아가면 그대로 핫핑크다** — 속성이 사라지면 토큰이 되돌아온다. 되돌리기 · 다른 색은 Alan 에게 묻는다.
  - **상태 표시줄 · 브라우저 색(`theme-color`)도 모드를 따른다** (2026-10-11 Alan — 아이폰 홈 화면 앱의 관리자 대시보드 위에 "핑크줄이 있는데 새로고침을 하면 없어져").
    값은 `src/lib/theme-color.ts` 한곳 — 학생 모드 · 랜딩은 브랜드 핫핑크(`BASE_VIEWPORT`, manifest · offline.html 과 같은 값), **`/admin` 레이아웃은 `ADMIN_VIEWPORT` 로 관리자 바탕
    회색(`--color-surface` = `#f2f4f6`)** 을 내보낸다 (Next 는 안쪽 레이아웃의 `viewport` 를 바깥 것 위에 겹치고, 화면을 옮기면 메타 태그를 바꾼다 — 브라우저로 확인).
    `admin-theme.test.ts` 가 globals.css · manifest · offline.html 과 같은지 본다. **핑크 줄의 까닭은 이 환경에서 못 확정했다** — 그날 캡처 둘을 재 보니 핑크는 `#eb4587`(브랜드 `#ff2e88` 이 아니라
    스플래시 포스터 JPEG 의 핑크에 가깝다) · 회색은 `#f2f4f6`(관리자 바탕) 이어서, **아이폰이 앱을 켤 때 처음 그려진 스플래시(`AppSplash`, 핑크) 색을 잡아 두고 새로고침해야 다시 잡는** 쪽으로 보인다.
    그 가설이면 메타 색을 바꿔도 앱을 켠 직후의 핑크 줄은 남는다 — Alan 에게 "앱을 완전히 닫았다 켜기" 로 다시 보라고 했다. 그래도 남으면 스플래시가 끝날 때 상태 표시줄 색을 다시 알리거나
    스플래시 위쪽 띠를 바탕색으로 두는 것을 다음에 본다 (먹히는지는 실기기로만 안다).
- **명단에 적힌 사람 이름·전화번호는 검은 글자다** (2026-09-18 Alan — 학생명단을 보고 "글, 숫자 색상을 검은색으로").
  분홍 글자로 두면 한 줄에 분홍이 이름·번호·등급 칩까지 셋이라 어디를 봐야 할지 흐려진다. 강조는 등급 칩 하나로 충분하다.
  전화·메일처럼 **누르면 무언가 일어나는 값**에는 **연분홍 밑줄**(`decoration-brand-200`, 누르면 진해진다)을 남긴다 —
  **밑줄까지 빼지 말 것.** 색만 빼면 눌러도 되는 줄인지 알 수 없다 (휴대폰에는 hover 가 없다)
